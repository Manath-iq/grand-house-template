# Сайт Grand House — Набережные Челны

Одностраничник для строительной компании: каменные дома под ключ, чек 5–13 млн ₽,
Челны и Тукаевский район. Одна задача страницы — довести человека до заявки
в WhatsApp.

Сейчас это **предварительный макет**, а не боевой сайт компании. Что в нём
настоящее, а что образец — в [ЗАМЕНИТЬ.md](ЗАМЕНИТЬ.md). Читать до отправки.

```bash
npm install
npm run dev        # разработка
npm run build      # сборка в dist/ (шрифты пересобираются сами)
npm run preview    # посмотреть собранное
npm run check      # типы
npm run contrast   # проверка палитры на 4.5:1
npm run plans      # перерисовать планировки
```

## Как устроено

| Слой | Что | Где |
|---|---|---|
| Данные компании | реквизиты, проекты, цены, этапы, отзывы | `src/config/client.ts` |
| Слова интерфейса | заголовки блоков, подписи кнопок | `src/config/copy.ts` |
| Цвета | вся палитра | `src/config/tokens.ts` |
| Вёрстка | блоки и раскладка | `src/components` |

Два правила, и оба проверяемы:

- **ни одного хекса вне `tokens.ts`** — цвета инлайнятся в `<html style="…">`
  и раскладываются по смысловым токенам в `src/styles/tokens.css`;
- **ни одной текстовой строки в компонентах** — слова из `copy.ts`, данные
  из `client.ts`.

```bash
grep -rnE "#[0-9a-fA-F]{6}" src/components src/layouts src/pages src/styles
```

Пусто — значит правило держится.

### Проверки на сборке

`src/config/index.ts` роняет сборку, если конфиг противоречив: доли оплаты
по этапам не дают 100%, слои этапов идут с пропуском, у проекта нет цены,
или снят флаг макета при незаполненных реквизитах. Лучше упасть на сборке,
чем показать заказчику схему платежей, которая не сходится.

## Блоки

Порядок — это порядок разговора с покупателем. Каждый следующий снимает
возражение, которое возникает от предыдущего.

Hero → полоса доверия → почему камень → каталог с ценами → комплектации →
этапы и схема дома → безопасность денег → оплата и ипотека → построенные
объекты → кто ведёт стройку → отзывы → FAQ → квиз → подвал.

Сквозное: липкая шапка с телефоном, липкая панель «Позвонить / WhatsApp»
на мобильном после первого экрана, один и тот же текст действия —
«Рассчитать смету» — на всех кнопках и в заголовке модалки.

### Signature-элемент

Схема дома в блоке этапов собирается по мере прокрутки: фундамент → коробка →
кровля → окна и фасад → инженерия. Порядок строительный, а не «снизу вверх
по картинке»: кровлю ставят раньше окон, и человек, который строил, это знает.
Рядом с каждым слоем срок и доля оплаты, поэтому анимация заодно снимает
главное возражение ниши — «отдам деньги и останусь без дома».

Реализация — `IntersectionObserver` плюс CSS-переходы. Ни GSAP, ни Lenis:
на пять карточек библиотека не даёт ничего, чего не даёт наблюдатель,
а весит больше всего остального JS вместе взятого.

### Заявка

Сервера у статики нет. Квиз открывает `wa.me` с готовым текстом — их
собственный канал и их собственный номер. Токен Telegram-бота в браузер
не кладётся: в собранном сайте любой ключ в JS виден всем. Понадобится
Telegram — между сайтом и ботом ставится функция на Cloudflare Workers,
её адрес становится `lead.endpoint` в конфиге.

## Грабли, на которые уже наступили

**Скоуп стилей Astro.** Компонент `Reveal` рисует элемент за вызывающего,
и атрибут `data-astro-cid-*` на него сам не попадает — он приходит пропом.
Без `{...rest}` в `Reveal.astro` правила вида `.trust__item[data-astro-cid-…]`
не совпадают ни с чем, и раскладка блока молча пропадает: ни ошибки в консоли,
ни падения сборки, только неверная страница.

**Липкий блок в гриде.** `align-items: start` ужимает колонку по содержимому,
и `position: sticky` внутри неё перестаёт работать — ехать некуда. Колонка
обязана растягиваться на высоту строки.

**IntersectionObserver сообщает только текущее состояние.** Всё, через что
пролистнули быстрым махом или перепрыгнули по якорю, наблюдателю не достаётся
вообще. Поэтому блоки выше экрана показываются сразу, а пропущенные слои дома
достраиваются: иначе на схеме появляется дом с окнами, но без кровли.

**resvg и шрифты в OG-превью.** woff2 он не читает; `fontBuffers` молча
игнорирует, работает только `fontFiles`; вариативные шрифты не инстанцирует
и берёт начертание по умолчанию — у Geologica это Thin, и заголовок превью
выходил волосяным. Поэтому для превью подключены отдельные статические
`@fontsource/*`, а сопоставляет шрифты resvg по имени внутри ttf, которое
не совпадает с CSS и включает вес («Onest SemiBold»). Имя читается из таблицы
`name`, а не захардкожено: Fontsource его меняет между версиями.

**Знак рубля U+20BD** лежит в субсете `latin-ext`. Без него цифры цены
рисуются своим шрифтом, а рубль — системным, и это видно невооружённым глазом.

## Внешний вид

Светлый премиум-камень: тёплый десатурированный офф-вайт, графит, один
акцент — зелёный с фирменного знака компании. Кремовый фон с терракотой
не взят сознательно: это самая узнаваемая пара в нише ИЖС, по ней сайт
мгновенно опознаётся как шаблон.

Все 20 пар «текст / фон» проверяются на 4.5:1 скриптом `npm run contrast`,
который читает цвета из `tokens.ts` — проверка не устаревает при смене
фирменного цвета, а ломается контраст как раз тогда, когда клиент присылает
свой.

Типографика: дисплейная **Geologica** только на заголовках и цифрах-героях,
основная **Onest**, моноширинная **Martian Mono** на площадях, сроках и ценах.
Моноширинный для цифр не украшение: `168 м² · 6 мес · от 9 240 000 ₽`
читается как факт, набранное гротеском — как маркетинг.

## Публикация

Демо собирается на GitHub Pages в подпапку репозитория и закрыто `noindex`,
чтобы не конкурировать в выдаче с будущим боевым сайтом компании.

При переезде на свой домен адрес и префикс передаются окружением —
захардкодить их нельзя, иначе на боевом домене все пути уедут:

```bash
SITE_URL=https://grandhouse.example SITE_BASE=/ npm run build
```
